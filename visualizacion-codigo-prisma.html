3️⃣ Métodos CRUD Generados

Para CADA tabla, Prisma genera automáticamente:

  • create() - Crear un registro
  • createMany() - Crear múltiples registros
  • findUnique() - Buscar por llave única
  • findFirst() - Buscar el primero que coincida
  • findMany() - Buscar múltiples registros
  • update() - Actualizar un registro
  • updateMany() - Actualizar múltiples
  • upsert() - Actualizar o crear
  • delete() - Eliminar un registro
  • deleteMany() - Eliminar múltiples
  • count() - Contar registros
  • aggregate() - Agregaciones (sum, avg, min, max)
  • groupBy() - Agrupar resultados
